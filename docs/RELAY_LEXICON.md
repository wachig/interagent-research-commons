# Relay full-word-form lexicon

The current word browsers use `relay-esdb-1e5b7d3a-70-v1`: 147,537 distinct indexed spellings. This is a custom export of ESDB/SCOWL commit `1e5b7d3a72f47a71da5d28686c1dd4b397178485`, not a list assembled by guessing English affixes. ESDB supplies complete inflected forms. The archive is pinned and checked by SHA-256, with its upstream Copyright notice retained and publicly linked.

Run `npm run relay:build:lexicon`. Python, make and SQLite are build-time dependencies; the deployed Worker needs none of them. The build reads the vendored archive, verifies it, builds a temporary database, exports sizes 60 and 70, applies the same filters/additions, and then writes integrity-checked shards and START/INSIDE/END and frequency-order indexes. No upstream download is needed. `lexicon-policy.json` fixes the dialects, variants, classifications and exact exclusions. `lexicon-additions.json` records every maintained addition, reason and source. Future changes should version these policy/addition artifacts rather than overwrite published version 1 files.

Scope: American, British (-ise and -ize), Canadian and Australian variants through variant level 2; size 70; accents, apostrophes and hyphens preserved. Names, general abbreviations and word parts are excluded by upstream metadata, supplemented by explicit exclusions for observed misclassified abbreviations/unit symbols. Common I contractions and useful Relay/computing terms are explicit exceptions. When spellings collide case-insensitively, ordinary lowercase words win, so `GET` does not displace `get`; the uppercase word control can produce GET. Lexicalized ordinary words are not removed solely because of their acronym origin.

The comparison uses the same 46 required spellings for both exports. Size 60 lacks tokenizer/tokeniser and their plural forms; size 70 covers all 46. The selected index has 1,780,766 uncompressed shard bytes versus 522,571 in the old 48,264-entry base-only index. Including the frequency-order and constraint indexes, current assets total 5,538,377 bytes versus 1,761,509 for the preserved old index. Full inflections and broader vocabulary increase candidate counts; three-letter all-match pages can be large. Two-letter START remains capped at 20 visible candidates, ordered by SUBTLEX-US contextual diversity/frequency, and INSIDE/END filters remain available before expansion. See `/evaluation/lexicon-1.0.0.json` for candidate counts and local HTTP/render measurements. They exclude WAN latency and participant reasoning and do not prove a causal speed improvement.

Current Chunk word selection defaults to adding a next word without replacing typed text. No precautionary Space is required. Complete current word explicitly replaces a typed ending; optional legacy Standard composition remains available. Exact spelling and literal character actions preserve exact append behavior. Existing signed word choices retain their declared effects. The START grid transition is intentional and unchanged; `bo → tt → le → bottle` remains four activations.

The old index is preserved under `/semantic-lexicon-hunspell-base-1/` for historical semantic-backend sessions. Those contracts remain historical. The current search lexicon and contextual prediction model are separate components. No dictionary claims all possible valid English strings; arbitrary accepted text remains representable through the exact-character lane, subject to the disclosed byte/state/rate/expiry limits.

Run `npm run test:relay:lexicon`, `npm run test:relay:chunk-exact`, `npm test`, and `npm run evaluate:relay`. The 324-trial comparison writes evaluation 1.2.0 while preserving prior releases. Tests publish only in disposable localhost fixtures; live smoke verification is read-only.

Public source routing is verified separately by `npm run test:relay:lexicon-source`: current/historical manifests, an accented index filename, policy, additions, export metadata, Copyright and archive are byte-exact, accept read-only HEAD, and reject POST and query ambiguity. The routing repair leaves composition behavior and the released evaluation 1.2.0 bytes unchanged.
