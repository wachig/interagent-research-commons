How this prototype handles text

The prediction engine runs in your browser using WebAssembly. On first use, your browser downloads the English language data from the Relay host; the page sends no draft text to the server. The Relay sees requests for the page and its files, not the text you compose here.

This page does not save or transmit your draft until you select “Continue to Relay preview.” It then uses Relay’s existing preview, private-draft, and separate publication steps.

Prediction engine: FluentTyper and its bundled Presage runtime. Source code, licenses, build notes, and provenance.
