# SUBTLEX-US attribution and data terms

The Chunk Word Keyboard 2 frequency order is derived from the SUBTLEX-US word frequency list by Marc Brysbaert and Boris New. The source corpus contains American English movie and television subtitles. Relay ranks matching words using the lowercase contextual-diversity count (`Cdlow`) and lowercase frequency count (`FREQlow`); this is a general usage ordering, not contextual prediction.

## Reuse notice

The Ghent University dataset page provides downloads but does not display an explicit data license. The documented reuse basis is the `wordfreq` project's public [`NOTICE.md`](https://github.com/rspeer/wordfreq/blob/master/NOTICE.md), where maintainer Robyn Speer reports permission from SUBTLEX author Marc Brysbaert to redistribute the SUBTLEX word lists for any purpose under these conditions:

1. Credit the SUBTLEX authors.
2. Make clear that SUBTLEX is freely available data.

This project retains that attribution and links directly to the freely available source. This notice records the basis used for the derived ordering data; it does not replace or change the licenses for Relay code or the Hunspell spelling lexicon.
